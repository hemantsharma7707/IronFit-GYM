🏋️ IronFit Jaipur

A modern, responsive gym and fitness website built using HTML and Tailwind CSS.
The website provides information about gym memberships, services, gallery, testimonials, and contact details.

🚀 Getting Started

1. Clone the repository

git clone https://github.com/your-username/ironfit-jaipur.git

2. Open the project

Navigate into the project folder:

cd ironfit-jaipur

3. Run the website

Since this project uses HTML and Tailwind CSS through the CDN, no installation is required.

Simply open:

index.html

in your browser.

For the best development experience, you can use Live Server in VS Code.

📱 Responsive Design

The website is designed to work across different screen sizes:

* 📱 Mobile
* 📲 Tablet
* 💻 Laptop
* 🖥️ Desktop

Tailwind CSS responsive breakpoints such as sm, md, lg, and xl are used throughout the project.
